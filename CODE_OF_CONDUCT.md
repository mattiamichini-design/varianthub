# Code of conduct

VariantHub follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests, discussions and any other space where people work on the project.

Report unacceptable behavior to the maintainer, [@mattiamichini-design](https://github.com/mattiamichini-design). If the report needs to stay private, use the private reporting form on the repository's Security tab and say that it concerns conduct. Reports are handled confidentially, and the maintainer applies the enforcement guidelines described in the Covenant.
