# Persist exploration layout with the repository and separate source dates from visits

Artboard arrangement, dimensions and comparison settings are saved with the repository when a drag or resize finishes, so committing those files transfers the workspace to another computer. Personal opening history stays in the browser. Displayed source history comes from repository metadata or Git; visiting a variant never creates a creation or modification date. Layout changes are visible in Git, because portable arrangement and consistent dates matter more than an untouched working tree. Repository writes are limited to the local development integration.
